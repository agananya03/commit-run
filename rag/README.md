# rag

FastAPI service on **:8000** (Python 3.11, Pydantic v2). Ingests forum JSON, PDFs, social posts and calldata for a proposal, then serves `/summarize` and `/extract-intent`.

Models must follow [`/shared/schemas/json`](../shared/schemas/json). Endpoints: [`/shared/API.md`](../shared/API.md)

Owner: RAG teammate. Status: not started.
