# sim

Simulation API on **:4002**. Executes a proposal's Timelock calldata on a fork of the local Hardhat chain and reports decoded calls, ownership/role/approval/implementation/selector changes and gas benchmarks.

Responses must follow [`/shared/schemas/json`](../shared/schemas/json). Endpoints: [`/shared/API.md`](../shared/API.md)
