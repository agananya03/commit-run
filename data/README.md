# data

Synthetic Meridian DAO scenarios used for the demo:

- **MIP-12**: clean proposal, text matches execution.
- **MIP-17**: conflict-of-interest case (proposer-linked beneficiary wallets).
- **MIP-21**: "gas optimisation" reserve upgrade that secretly adds `migrateReserves(address)`, moves ownership to the proposer's alt wallet and grants it an unlimited USDC approval.

Each scenario holds its forum JSON, PDF, social posts and calldata.
